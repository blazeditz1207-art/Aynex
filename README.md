# AYNEX AI 1.1

Next.js + Gemini foundation for the AYNEX ecosystem.

## Features
- AYNEX Core / Pro / Code
- Vision and Voice architecture
- AYNEX Imagine image generation
- Correct Next.js App Router folders
- Gemini API via GEMINI_API_KEY
- Vercel-ready deployment

## Deploy
Keep `package.json` and `app/` at the repository root. In Vercel add `GEMINI_API_KEY` as an Environment Variable, then deploy. Never commit the real key.
